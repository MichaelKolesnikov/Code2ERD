ERD language quick reference

The text describes entities, their attributes and the relationships between them; the diagram is drawn in Chen notation and follows the text as you type. Keywords and settings are case-insensitive, names are not.

Entities

Entity Student [color: #dcebfa, note: 'Anyone enrolled'] {
  student_id [key]
  "full name"
  phone [multivalued]
  age [derived]
}

Entity Dependent [weak] {
  name [partial key]
}

Entity Room           // no attributes: no braces needed
weaka weak entity: double rectangle
color: #rrggbbfill color of the shape
note: 'text'shown in the tooltip

Attributes

One attribute per line, or separated by commas. A name with spaces goes in double quotes.

key or pkkey attribute: underlined
partial key or partialdiscriminator of a weak entity: dashed underline
multivalued or multiseveral values: double ellipse
derivedcomputed from other attributes: dashed ellipse
note: 'text'shown in the tooltip

A composite attribute lists its parts in braces, as deep as needed:

address {
  street { name, number }
  city
}

Relationships

Relationship Enrolls [color: #fde6d2] {
  Student (0, N)
  Course (1, N) [total]
  grade
}

Relationship Has [identifying] {
  Employee (1)
  Dependent (N) [total]
}

A line Entity (cardinality) connects the entity; the other lines are attributes of the relationship. A relationship connects at least two entities, any number for a ternary or n-ary one.

(N), (1), (M)one value, written next to the entity: 1:N, M:N
(0, N), (1, 1), (1, *)(min, max): how many times the entity takes part; min is a number
totaltotal participation: double line
role: 'text'the role of the entity, written in the middle of the line
identifying (relationship)identifies a weak entity: double diamond

A recursive relationship lists the same entity twice; the two lines curve apart:

Relationship Supervises {
  Employee (0, 1) [role: 'subordinate']
  Employee (0, N) [role: 'supervisor']
}

On the diagram

Shift+drag on the canvasselect several shapes
Ctrl+wheelzoom
Right click a shapearrange its attributes around it again
